# Повышенные права доступа

Права администратора, выгрузки данных и доступ сверх [[Стандартный набор доступов]] выдаются только по заявке:

1. Сотрудник описывает задачу (зачем нужен доступ и на какой срок).
2. Заявку согласует руководитель.
3. Заявку согласует служба ИБ — до 2 рабочих дней.

Бот может только подготовить черновик заявки. Выдавать права бот не может. Правила — в [[Политика ИБ кратко]].
