# Политика ИБ кратко

- Не передавайте пароли и коды 2FA никому, включая коллег и «IT-поддержку» в мессенджерах.
- Клиентские данные не выгружаются на личные устройства и во внешние сервисы.
- Подозрительные письма пересылайте в ИБ, см. [[Контакты]].
- Доступы сверх стандартных — только через [[Повышенные права доступа]].

Тест по ИБ входит в [[Обязательное обучение]], сдаётся в течение первых 2 недель.
Для [[Отдел маркетинга]] — отдельный блок про работу с персональными данными в рассылках.
